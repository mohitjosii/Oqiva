# Phase 1 spikes

Throwaway experiments that settle two risks before the real code is written. They are
not part of the app and ship nothing. Results are recorded in `docs/DECISIONS.md`
(ADR-003 and ADR-009).

| Folder | Question |
|---|---|
| `renderer/` | How many objects can an SVG canvas hold and still pan, zoom and drag smoothly? |
| `realtime/` | Can a relay inside Frappe's own socket server carry Yjs sync safely? |
